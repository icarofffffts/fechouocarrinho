# Telas do app

12 telas em PNG (`01 Home` até `12 Sincronização`, 390 × 880).

- `build_app_design.js` gera `app-screens.json`, o deck das 12 telas para o FigCraft: `node build_app_design.js`.
- `app-screens.figcraft` é o arquivo aberto no FigCraft.
- Os PNGs são as telas exportadas dali. Nenhum script daqui gera os PNGs, então exporte de novo no FigCraft quando o deck mudar.
