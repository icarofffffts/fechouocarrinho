# Site

`paginas-internas/` tem o layout das 6 páginas internas do site (Como funciona, Supermercados, Comparador, Ajuda, Marca e
Privacidade) em PNG, com `internal-pages.json` e `internal-pages.figcraft` como origem editável.

O site em si está em `fechouocarrinho-next/` e roda com `npm run dev` (porta 3000 por padrão; use `-p 3100` se estiver ocupada).
